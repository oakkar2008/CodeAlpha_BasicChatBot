# ChatBot - CodeAlpha Task 4

## Description
A simple rule-based chatbot that responds to predefined questions and greetings. The chatbot uses if-elif statements and functions to match user input with predefined responses.

## Features
- ✅ Predefined Q&A responses
- ✅ Case-insensitive input handling (.lower())
- ✅ Simple rule-based logic
- ✅ Exit on "bye" command
- ✅ User-friendly interface

## Technologies Used
- Python 3
- Functions
- Loops (while)
- Conditionals (if-elif)
- Dictionaries
- String operations

## How to Use
1. Run the program: `python app.py`
2. Type your message and press Enter
3. Bot responds with predefined answer
4. Type "bye" to exit

## Skills Demonstrated
- Function design
- Dictionary usage
- Loop control
- Input/output handling
- String case conversion
